# Working With AI Coding Assistants

## Core Mindset

1. **AI as Pair Programmer**: Treat AI coding assistants as capable junior/mid-level pair programmers. Guide them with explicit success criteria and empirical verification steps.
2. **Progressive Disclosure**: Keep prompt context clean. Never paste massive files or entire codebases into prompt windows upfront. Let the AI locate and read only what is needed.
3. **Ask, Don't Guess**: Encourage the AI to ask clarifying questions whenever requirements, stack details, or deployment rules are underspecified.
4. **Verification Over Assertion**: Never accept an AI's claim that a bug is fixed or tests passed without seeing real execution output or manual test steps.
